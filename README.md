# Taskflow web

A responsive browser companion for the Task Manager Android app. It includes a daily overview, interactive task list, theme switch, and quick sketch canvas.

## Run

Open `index.html` in a modern browser. Tasks and theme preferences are saved in local browser storage. This static prototype does not connect to Firebase or sync with the Android app.

## Publish

The GitHub Pages workflow publishes the repository after Pages is configured to use GitHub Actions.
